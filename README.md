# PHP Distance Radius Search

This project allows you to search for locations within a specific radius using PHP and MySQL. No 3rd-party APIs are required.

## Setup

1. Create a MySQL database.
2. Import `database.sql`.
3. Update `config.php` with your database credentials.
4. Open `index.php` in a browser.

## Usage

- Input latitude, longitude, and radius (km) in the form.
- Results will show all locations within the specified radius.
